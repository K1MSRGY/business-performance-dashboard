# Business Performance Dashboard

## Описание проекта

Интерактивный Power BI дашборд для анализа ключевых бизнес-показателей компании.

Проект включает анализ:

- продаж
- прибыли
- клиентов
- регионов
- логистики
- складов
- эффективности сотрудников

## Инструменты

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Основные показатели

В дашборде рассчитаны и визуализированы:

- Total Sales
- Profit
- Profit Margin
- Average Order Value
- Returns Rate
- Shipping Cost Ratio
- Revenue per Employee

## Что было сделано

- Подготовка и очистка данных в Power Query
- Построение модели данных
- Создание DAX-мер
- Расчет KPI
- Анализ продаж по регионам
- Анализ клиентов
- Анализ логистики и складов
- Анализ эффективности сотрудников
- Создание интерактивных фильтров и визуализаций

## Результат

Дашборд позволяет быстро оценивать основные показатели бизнеса, сравнивать результаты по регионам и выявлять проблемные направления.
